About the Role

Twitch's Enterprise Platform & Technology (EPT) organization is looking for a Software Development Engineer II to build the systems where SAP meets AWS — extending our enterprise ERP with cloud-native services and agentic AI to power Finance and enterprise functions across Twitch and Amazon. This is a hands-on engineering role where you'll work on SAP-side development (ABAP, CDS, RAP, OData) and AWS-native engineering (Lambda, Step Functions, MCP servers, Bedrock, CDK) — owning integrations end-to-end.

You'll work at the intersection of SAP enterprise systems and modern cloud engineering — building AWS-hosted APIs and pipelines that talk to SAP, standing up agentic AI tooling (MCP servers, Bedrock agents, Claude-powered workflows) that automates Finance operations, and shipping production AWS services alongside SAP customizations. The business problems are well understood; how you solve them with SAP + AWS + AI is up to you. We're looking for an SAP developer whose toolkit has grown past the ERP — someone who writes ABAP inside SAP GUI and is just as ready to pick up Python or TypeScript to ship the cloud half of their own integration, and who raises the bar on automation along the way.

You Will

Build in SAP

- Design, build, and maintain integrations between SAP (S/4HANA, BTP) and downstream systems — owning the full lifecycle from design through operations

- Write ABAP, SAP HANA SQL, and CDS views to implement business logic, reports, and data transformations within the SAP ecosystem

- Design, build, and maintain SAP APIs — OData services (SEGW / RAP), RESTful APIs, SOAP web services, and RFC-based interfaces — for consumption by external systems, Fiori apps, and AWS-hosted middleware

Extend it with AWS and agentic AI

- Build and operate AWS-native services (Lambda, Step Functions, API Gateway, S3, DynamoDB, ECS/Fargate, Amazon ECR) that extend SAP capabilities beyond the traditional ERP boundary

- Deploy and manage the AWS infrastructure behind your integrations using CDK (TypeScript/Python) — including CI/CD pipelines, IAM roles, VPC/VPCE connectivity to SAP, and multi-environment topology (beta/gamma/prod)

- Design, build, and ship agentic AI systems on top of your SAP APIs — MCP (Model Context Protocol) servers, Bedrock-based agents, and Claude-powered workflows — that automate Finance operations like reconciliations, reporting, variance analysis, and payout workflows

- Build data pipelines that move financial data between SAP, Redshift, and enterprise applications

Cross-cutting

- Collaborate with Finance, Accounting, and Tax stakeholders to translate business requirements into technical solutions delivered across SAP and AWS

- Own production systems end-to-end — deployment, monitoring, incident response, and iterative improvement

- Improve engineering practices on the team through code reviews, documentation, and mentoring

You Have

SAP

- 4+ years of hands-on SAP development experience (ABAP, HANA SQL, CDS views, BTP, or SAP integration technologies like BAPIs, RFC)

- Experience building integrations using File-Based and API-Based (REST, OData, SOAP) patterns

- Experience with the S/4HANA top-down development approach — CDS views (with associations, annotations, parameters) and AMDP classes to push data processing to HANA from the ABAP layer

AWS and AI

- Hands-on experience with AWS services (Lambda, S3, Step Functions, DynamoDB, IAM, API Gateway, or similar) — deploying and operating production workloads

- Proficiency in at least one modern language beyond ABAP — Python, TypeScript/JavaScript, or Java — with a demonstrated track record of shipping production code

- Experience with infrastructure-as-code (CDK, Terraform, or CloudFormation) — writing, deploying, and reviewing IaC in a team setting

- Demonstrated heavy use of AI tools (Claude, Copilot, Bedrock, or similar) integrated into your daily engineering workflow — code generation, data analysis, automation, and problem-solving

Shared

- Experience testing and debugging APIs using tools like Bruno or Postman — building request collections, handling authentication flows, and validating response contracts

- Understanding of OAuth 2.0 authorization flows (authorization code, client credentials) and OpenID Connect (OIDC) for securing API integrations

- Strong understanding of object-oriented design patterns (Factory, Strategy, Observer, Template Method) and SOLID principles

- Finance domain knowledge — familiarity with FI/CO, FI/CA, AP, AR or GL

Bonus Points

- Experience building AI-powered automations or agentic workflows in production — MCP servers, Bedrock agents, LangGraph, or similar

- Experience building Fiori applications using the RESTful ABAP Programming Model (RAP) — including business object definition, behavior implementation (managed, unmanaged, or hybrid), and service binding/exposure
